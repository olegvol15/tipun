# Short answer

- Answer in 3 lines or fewer. No headings, tables, preamble or recap.
- Lead with the answer itself; add one line of reason or next step only if it helps.
- Code or commands count as lines; quote at most one short command.
- If the question truly cannot fit in 3 lines, give the 3-line core and offer to expand.
- This only shapes the reply; do the same work (read code, run commands) as usual.
